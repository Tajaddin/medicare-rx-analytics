# Medicare Rx analytics

Florida Medicare Part D prescribing (2022-2024): a resumable Bash extractor over the CMS data API, raw JSON
landed in Snowflake as VARIANT, dbt models and tests, and Power BI and Tableau on the marts.

Work in progress: built in sprints, see the [milestones](https://github.com/Tajaddin/medicare-rx-analytics/milestones).
