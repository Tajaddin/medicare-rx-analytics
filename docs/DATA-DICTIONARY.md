# Data dictionary

Generated by `scripts/data_dictionary.py` from the exported marts (types) and `dbt/models/schema.yml`
(descriptions, grain). These are the tables Power BI and Tableau read.

## mart_drug_spend_trend

Spend per generic name, class and year in Florida, YoY growth, national cost per claim.

Grain: one row per `generic_name`, `drug_class`, `data_year`.

| Column | Type | Meaning |
|---|---|---|
| `generic_name` | string |  |
| `drug_class` | string | class from the reviewed rules in seeds/drug_classes.csv (ADR 0004); `other` = untracked |
| `data_year` | int64 |  |
| `claims` | double | Part D claims (prescriptions and refills) |
| `fills_30day` | double | claims standardised to 30-day supplies |
| `drug_cost` | double | gross Part D drug cost, US$, before manufacturer rebates |
| `prescribers` | int64 | distinct prescribers (NPI) |
| `cost_per_claim` | double | drug_cost / claims |
| `national_cost_per_claim` | double | same generic name, all states, from Part D Spending by Drug |
| `cost_growth_yoy` | double | drug_cost against the same generic name and class a year earlier; empty in the first year |
| `cost_rank_in_year` | int64 | rank by drug_cost within the year (1 = largest) |

## mart_generic_opportunity

Upper-bound saving if brand fills had cost what the same generic name's fills did.

Grain: one row per `generic_name`, `drug_class`, `data_year`.

| Column | Type | Meaning |
|---|---|---|
| `generic_name` | string |  |
| `drug_class` | string | class from the reviewed rules in seeds/drug_classes.csv (ADR 0004); `other` = untracked |
| `data_year` | int64 |  |
| `brand_fills` | double | 30-day fills of branded products with this generic name |
| `brand_cost` | double |  |
| `generic_fills` | double | 30-day fills dispensed as the generic |
| `generic_cost` | double |  |
| `brand_cost_per_fill` | double |  |
| `generic_cost_per_fill` | double |  |
| `savings_upper_bound` | double | brand_cost minus brand_fills x the generic's cost per fill, floored at 0; an upper bound |
| `brand_share_of_fills` | double | brand_fills / (brand_fills + generic_fills) |

## mart_opioid_by_city

Cities with at least 20 prescribers only.

Grain: one row per `city`, `data_year`.

| Column | Type | Meaning |
|---|---|---|
| `city` | string |  |
| `data_year` | int64 |  |
| `prescribers` | int64 | distinct prescribers (NPI) |
| `all_claims` | double | every Part D claim by the city's prescribers |
| `opioid_claims` | double | claims in class opioid_analgesic (CDC definition; cough products excluded) |
| `opioid_day_supply` | double | days' supply of those claims |
| `oud_treatment_claims` | double | buprenorphine claims for opioid use disorder (naltrexone excluded, see ADR 0004) |
| `opioid_prescribers` | int64 | prescribers with at least one opioid analgesic row |
| `opioid_share_of_claims` | double | opioid_claims / all_claims |
| `oud_treatment_per_opioid_claim` | double | oud_treatment_claims / opioid_claims |
| `avg_opioid_days_per_claim` | double | opioid_day_supply / opioid_claims |

## dim_drug

Products seen in Florida with class and the national 2024 unit price.

Grain: one row per `brand_name`, `generic_name`.

| Column | Type | Meaning |
|---|---|---|
| `brand_name` | string |  |
| `generic_name` | string |  |
| `drug_class` | string | class from the reviewed rules in seeds/drug_classes.csv (ADR 0004); `other` = untracked |
| `is_brand` | bool | true when CMS's brand name differs from the generic name |
| `fl_claims_all_years` | double | Florida claims, all loaded years |
| `fl_cost_all_years` | double | Florida drug cost, all loaded years |
| `national_manufacturers_2024` | int64 | manufacturers of the product nationally, 2024 |
| `national_spend_per_unit_2024` | double | average spending per dosage unit nationally, 2024 (weighted) |
| `national_spend_per_claim_2024` | double | average spending per claim nationally, 2024 |
| `national_price_outlier_2024` | bool | CMS flags the unit price as an outlier for 2024 |
